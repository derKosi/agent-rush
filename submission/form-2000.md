## Short Description — 235/255

```
An agent triages an untrusted package before install: it plans probes, runs them in a hardened container on Vultr, and returns a verdict backed by the egress proxy log, the process result and a filesystem diff the package cannot write.
```

## Long Description — 1979/2000

```
Every pip install runs a stranger's code before anyone has read it. Quarantine puts that moment behind glass: a model reads an untrusted package, decides which probes to run, and they execute in a hardened container on a Vultr VM — read-only root, no network, non-root, caps on memory, processes and time.

Three phases, because the obvious one is not enough. The build hook runs first: a source package's setup.py executes with the installer's rights. Then the package is installed and imported, because a payload that waits for first use never shows up in a build log. Then the declared dependencies are resolved — fetched as wheels, hashed, never installed, so no dependency's build backend ever runs.

The verdict rests on evidence the sandboxed process cannot write: the egress proxy log (what was attempted, and that it was denied), the process result, and a filesystem diff. Rules set the risk floor; the model may only raise it, and only by citing a source that exists in that run. A claim citing anything else is dropped — in testing, the model tried to raise a verdict with a citation that did not exist, and was refused.

Three runs show the spread. harborline 2.9.1 builds and imports cleanly and is blocked anyway: it pins urllib3 1.24.1, thirteen advisories, score 8.0 against a threshold of 7. quickchart-export 0.4.0 declares no dependencies at all, and its install hook tries to reach a collector host, write outside the build directory and read an SSH key — all three denied, each with a file behind it. telemetry-shim 1.1.0 builds clean and imports clean, and only on first use spawns a process and calls home; a dependency scanner passes it.

What it does not do, in the report as in this text: dependencies are listed and checked, never executed; what runs after the first import is out of scope; a detached child process is not prevented, and the report says spawned. 96 tests, MIT. Live: http://45.77.143.94/ — source: https://github.com/derKosi/agent-rush
```
