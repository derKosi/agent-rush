# Was hier liegt

Staging-Ordner für die Abgabe. Text ist versioniert, Medien sind lokal (gitignored) — ein Repo
mit zehn Megabyte Video bringt niemandem etwas.

| Datei | Wofür |
|---|---|
| `description.md` | Titel, Kurz- und Langbeschreibung, Tags — copy-paste ins Formular |
| `links.md` | Repo, Demo-URL, Video, Slides, Cover — die Felder, die eine URL verlangen |
| `cover.png` | Cover-Bild, 1920×1080 |
| `slides.pptx` | 12 Folien |
| `video-v1-andrew.mp4` | 1:53, männliche US-Stimme, Untertitel eingebrannt |
| `video-v2-ava.mp4` | 2:00, weibliche US-Stimme — **verworfen**, zeigte die Seite nicht |
| `video-v3-vivienne.mp4` | 1:49, französische Multilingual-Stimme, Untertitel eingebrannt |
| **`video-v4-andrew-topbar.mp4`** | 1:53, Andrew, **Topbar sichtbar**, ohne Untertitel |
| **`video-v5-vivienne-topbar.mp4`** | 1:49, Vivienne, **Topbar sichtbar**, ohne Untertitel |
| **`video-v6-vivienne-smallcaptions.mp4`** | 1:49, Vivienne, kleine Untertitel unten |
| `captions.srt` | Untertitel separat — für den Upload zu YouTube

Welches Video hochgeladen wird, entscheidet Kosi. Alle drei sind aus demselben Skript gebaut,
jedes mit eigener Taktung — keine ist ein Ausschnitt einer anderen.
