# Was hier liegt

Staging-Ordner für die Abgabe. Text ist versioniert, Medien sind lokal (gitignored) — ein Repo
mit zehn Megabyte Video bringt niemandem etwas.

| Datei | Wofür |
|---|---|
| `description.md` | Titel, Kurz- und Langbeschreibung, Tags — copy-paste ins Formular |
| `links.md` | Repo, Demo-URL, Video, Slides, Cover — die Felder, die eine URL verlangen |
| `cover.png` | Cover-Bild, 1920×1080 |
| `slides.pptx` | 12 Folien |
| `video-v1-andrew.mp4` | 1:53, männliche US-Stimme |
| `video-v2-ava.mp4` | 2:00, weibliche US-Stimme |
| `video-v3-vivienne.mp4` | 1:49, französische Multilingual-Stimme |

Welches Video hochgeladen wird, entscheidet Kosi. Alle drei sind aus demselben Skript gebaut,
jedes mit eigener Taktung — keine ist ein Ausschnitt einer anderen.
